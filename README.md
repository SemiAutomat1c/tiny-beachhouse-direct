# Tiny Beachhouse Direct

Marketing site for Tiny Beachhouse in Scheveningen, built with React, Vite, TypeScript, and Tailwind CSS.

## Development

- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build production bundle: `npm run build`
- Run tests: `npm test`

## Deploy To Vercel

- Import this repository in Vercel
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

The repository includes `vercel.json` with SPA routing fallback so direct visits to routes like `/accommodatie` and `/boeken` resolve correctly.
